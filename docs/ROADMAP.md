# Roadmap

## Next foundations

1. Connect a real Supabase project and run hosted sign-up, sign-in, result-save and Storage integration checks.
2. Bound the event and distractor pool before snapshotting very large remote catalogs; remote loading and active-game snapshots are implemented.
3. Expand source review and author different clues for each difficulty.
4. Calibrate map scales by geographic region and event footprint.
5. Add account history and statistics views using private saved sessions.
6. Create profile editing and automatic profile provisioning.
7. Add broader browser and assistive-technology testing.

## Later

Achievement awards, content review workflows beyond the implemented admin editor, richer cause chains and a public leaderboard backed by server-authoritative scoring. Multiplayer, subscriptions, tournaments, chat, friends and social feeds are intentionally outside this foundation.
