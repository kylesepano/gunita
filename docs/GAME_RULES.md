# Game rules

Each expedition has ten rounds. In Roulette mode, six categories are drawn independently with equal probability. In Who, Where, When, What, Why or How only mode, every round goes straight to the selected challenge without displaying or spinning a roulette.

| Category | Interaction                                                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Who      | Select a historical portrait. Easy shows names, medium shows context, hard focuses on the image. Descriptive image alternatives remain available for accessibility. |
| Where    | Pin a map location or type coordinates. Reveal shows both markers, a connecting line and Haversine distance.                                                        |
| When     | Move a year slider. Easy adds candidate years; medium/hard use wider ranges. Arrow keys provide precise selection.                                                  |
| What     | Combine year, person and location evidence to identify an event card.                                                                                               |
| Why      | Select all contributing causes. Incorrect selections reduce accuracy; selecting every card cannot earn full marks.                                                  |
| How      | Reorder four stages with dragging or move-up/down buttons. Partial ordering earns partial credit.                                                                   |

A score of at least 80% accuracy counts as a correct round for streaks and final statistics. Any lower accuracy resets the streak. A hint removes only the no-hint bonus; it never blocks play.

There is no answer deadline. Response time is wall-clock time from challenge appearance to submission, including time spent away from the page. A reload preserves that timestamp. Players can leave through **Save & leave** and continue from the landing page.

Map exceptions are explained in the event: Apollo 11 uses the Florida launch site, the Cry uses a commemorative site, Berlin uses a named crossing, and Normandy uses Omaha Beach to represent the broader landings.
